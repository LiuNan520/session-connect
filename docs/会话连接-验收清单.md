### 开始前

1. 点击程序坞里的「会话连接」，用本机 Chrome 验收。应用位于 `/Applications/会话连接.app`，使用当前项目的构建产物。
2. 先用「⋯ → 导出全部数据」保存一份现有数据，普通操作使用新建的“验收临时画布”，避免混入日常画布。
3. 准备 PNG、JPG、WebP、SVG 各一张、GIF 一张、超过 1 MB 的图片，以及一个可复制改名为 `.json` 的 30 MB 视频；性能夹具已在 `fixtures/perf-200.json`。
4. A5–A10、A40–A42 涉及进程、目录或故障，建议开发协助。A7/A40/A41/A42 使用独立测试数据：先退出应用及本项目其他服务，把整个 `~/.session-connect/` 临时移到一个不重名的备份位置，让应用重新建立测试目录。测完退出应用，另存测试目录，再恢复原目录；不要覆盖、合并或删除正式数据。
5. A8 修改项目路径或 `.app-config` 前先记录原值；验证完立即恢复。不要靠删除真实 Node.js 来模拟缺失。
