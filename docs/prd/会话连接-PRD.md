# 会话连接 PRD

- 版本：v8 · 2026-10-21
- 状态：已归档（2026-10-21；用户验收全部通过）
- 编写：Claude

## 1. 背景与目标

按 CLAUDE.md / AGENTS.md 的工作流开发时，一个功能要在 Claude Code 和 Codex 之间开好几个会话（方案会话、开发会话、审核会话、GPT），消息还要来回转发。会话一多，就分不清哪个会话负责什么、下一步该发给谁。

目标：做一个本地网站，用卡片代表会话，用带箭头的连线表示消息往哪边转发，一眼看清每个功能的会话关系和进度。

- 点一下程序坞里的「会话连接」图标就能用：自动在后台启动、自动打开浏览器，不用登录。
- 数据不丢：自动保存、启动时自动备份、可以导出。

## 2. 用语

| 词     | 含义                                                         |
| ----- | ---------------------------------------------------------- |
| 应用    | macOS 应用「会话连接.app」，放在「应用程序」文件夹和程序坞里。点击它就启动本地服务并打开浏览器。      |
| 本地服务  | 在本机后台运行的小程序，提供网页、读写数据文件。应用退出时它也停止。                         |
| 画布    | 一张可以无限平移、缩放的白板。可以有多张，在左侧"画布列表"里切换。                         |
| 当前画布  | 正在显示的那张画布。                                                 |
| 卡片    | 画布上的一个方块，通常代表一个会话。有图标、名称、备注、状态。                            |
| 状态    | 卡片的进度标记，四种：未开始 / 进行中 / 已完成 / 卡住了。                          |
| 连线    | 两张卡片之间的弯曲线，带箭头，可以写文字。一对卡片之间最多一条连线。                         |
| 方向    | 连线的箭头方向，三种：A → B、A ← B、A ⇄ B（双向）。                         |
| 连接点   | 鼠标移到卡片上时，卡片四条边中点出现的小圆点，从这里拖出连线。                            |
| 设置面板  | 页面右侧的面板，显示选中的卡片或连线的设置项。                                    |
| 选中    | 单击卡片或连线后的状态，显示黑色描边。                                        |
| 图标库   | 内置的 4 个图标，加上自己上传的图标。所有画布共用。                                |
| 数据文件  | 保存全部画布、卡片、连线、上传图标的文件，放在 `~/.session-connect/`。             |
| 备份    | 数据文件（含上传的图标）的历史副本，放在 `~/.session-connect/backups/`。                 |
| 未保存改动 | 页面里已经做了、但还没成功写进数据文件的改动。                                    |

## 3. 范围

### 本期做

1. macOS 应用「会话连接.app」：点击后在后台启动本地服务，并自动用默认浏览器打开网站；可以放进程序坞。
2. 多张画布：新建、重命名、删除、切换；每张画布记住自己的视野（平移位置和缩放）；重新打开时回到上次的画布。
3. 无限画布：平移、缩放、「适应全部」、小地图、点阵背景。
4. 卡片：新建（点击、拖放、右键空白处）、编辑（图标、名称、备注、状态）、移动、复制一张、删除、多选。
5. 连线：从连接点拖出来创建，或在设置面板里添加；可以改方向、写文字、删除；卡片"进行中"时，和它相连的连线变成流动的虚线。
6. 图标库：4 个内置图标，可以上传图标、删除自己上传的图标。
7. 撤销 / 重做。
8. 自动保存，显示保存状态，启动时自动备份。
9. 导出全部数据、导入。

### 本期不做

- 关联、读取本机真实的 Claude Code / Codex 会话（用户明确不需要，卡片名称自己填）。
- 任何卡片模板（用户明确不需要）。
- 登录、多用户、局域网或外网访问。
- 英文界面。
- 手机、平板适配；Windows、Linux（本地服务只支持 macOS，在其他系统上启动会直接报错退出）。

### 二期（候选，未承诺）

- 搜索卡片并定位。
- 分组框。
- 从连接点拖到空白处，直接新建一张卡片并连上。
- 画布排序、复制画布。
- 对齐、自动布局。
- 开机自动启动。
- 点应用图标时，如果浏览器里已经开着网站，就切到那个标签页，而不是新开一个。

### 已知限制

- 两个标签页同时编辑同一张画布：后保存的那个标签页会被拒绝，它被拒的那次改动会丢失（见 12.4）。
- 本地服务停止期间做的改动只在页面里；这时刷新或关闭页面会丢失这些改动（浏览器会弹出离开确认）。
- 撤销历史只在当前页面里，刷新后清空；一张画布载入了别的标签页的改动后（切回标签页时自动载入，或点「重新加载」），它的撤销历史也会清空。
- 超过 1 GB 的导出文件无法导入（按单个图标 1 MB 算，要大约 750 个上传图标才会碰到）。
- 删除画布、删除上传的图标、导入都不能撤销。
- 导入是"追加"：只新增画布，不覆盖也不合并现有画布；同一个文件导入两次会出现两份画布。
- 默认端口被其他程序占用时，服务会改用别的端口；如果两次启动用了不同端口，旧标签页连不上，要用新打开的标签页。
- 每点一次应用图标，都会在浏览器里新开一个标签页。
- 应用记住的是生成它时的项目目录；移动项目目录、或者更新代码后，要重新运行一次 `npm run app`。

## 5. 安装与启动

### 5.1 生成应用（一次性）

- 前提：本机已装 Node.js（版本要求在技术方案里定）。
- 在项目目录运行一次 `npm run app`（命令名以技术方案为准）：自动安装依赖、构建网页，生成「会话连接.app」并放进「应用程序」文件夹。终端最后打印"已生成：/Applications/会话连接.app，可以把它拖到程序坞"。
- 之后自己把它从「应用程序」文件夹拖到程序坞（不自动改程序坞）。
- 失败时终端显示原因，不生成应用、不改动已有的应用。
- 应用正在运行时再运行 `npm run app`：终端提示"会话连接正在运行，请先在程序坞里退出它再重新生成"，不做任何改动。
- 移动项目目录或者更新代码后，重新运行一次 `npm run app`。

### 5.2 日常使用

- 在程序坞、启动台或「应用程序」文件夹里点击「会话连接」：
  - 本地服务没在运行：在后台启动（不出现终端窗口），然后用默认浏览器打开网站。从点击到页面显示不超过 3 秒。程序坞图标下面出现小圆点，表示正在运行。
  - 本地服务已在运行：直接在默认浏览器里新开一个标签页打开网站。
- 停止：右键程序坞图标选「退出」，或者在应用处于前台时按 Cmd+Q。退出就会停止本地服务，小圆点消失。
- 本地服务意外退出（崩溃、被结束进程）：应用跟着退出，小圆点消失；再点图标就能重新启动。原因写进日志目录 `~/.session-connect/logs/`。
- 不用登录：打开网站直接进入上次打开的画布。
- 服务只监听 127.0.0.1，同一局域网里的其他设备打不开。
- 默认端口被其他程序占用：自动换一个可用端口，浏览器打开的就是实际地址。默认端口在技术方案里定。

### 5.3 启动失败

弹出系统对话框，只有一个「好」按钮；点了之后应用退出，不打开浏览器。

| 情况           | 提示                                                       |
| ------------ | -------------------------------------------------------- |
| 找不到 Node.js  | 找不到 Node.js，请先安装 Node.js 再打开会话连接。                         |
| 项目目录被移动或删除   | 找不到会话连接的项目目录：{路径}。如果移动过项目，请在新目录里运行 npm run app 重新生成应用。     |
| 其他原因         | 会话连接启动失败：{原因}。日志在 {日志目录}。                                |

### 5.4 开发时启动

- 在项目目录运行 `npm start`：在终端里启动本地服务并打开浏览器，关掉终端或按 Ctrl+C 就停止。
- `npm start` 和应用不会同时各起一个服务：
  - 应用已经在运行时运行 `npm start`：只打开浏览器，终端提示"会话连接已在运行，已打开浏览器"，然后退出。
  - `npm start` 已经在运行时点应用图标：只打开浏览器，应用随即退出，不接管这个服务。

## 7. 画布

### 7.1 画布列表

- 每行显示画布名称；当前画布高亮显示。
- 按创建顺序排列，新建的在最下面。
- 鼠标移到某一行时，右侧出现「⋯」，菜单里有「重命名」「删除」。

### 7.2 新建画布

- 点「+ 新建画布」：列表末尾出现新画布，名称处于编辑状态，默认叫"未命名画布"；如果已有同名画布，就自动加数字，如"未命名画布 2"。
- 按回车或点别处确认名称；按 Esc 放弃修改，保留默认名。
- 新画布自动成为当前画布，视野居中，缩放 100%。

### 7.3 重命名

- 双击名称，或从「⋯」选「重命名」：进入行内编辑。按回车或点别处保存，按 Esc 放弃。
- 去掉首尾空格后为空：恢复原名，并提示"名称不能为空"。
- 最多 30 个字，超过的部分输不进去。允许和其他画布重名。

### 7.4 删除画布

- 从「⋯」选「删除」：弹出确认框（文案见第 15 节）。点「取消」、按 Esc、点遮罩或 × 都不删除。
- 删除当前画布后，切换到列表里它上面那张；它上面没有，就切换到下面那张。
- 全部删光后：画布区显示空状态"还没有画布"和「新建画布」按钮；「+ 卡片」和撤销、重做都不可用。
- 删除不能撤销。

### 7.5 切换画布

- 单击列表里的画布即可切换。
- 如果切换时设置面板里有输入框正在编辑，先按"点别处"的规则保存这次输入，再切换。
- 每张画布记住自己的视野；撤销历史按画布分开保存，切走再切回来仍然可以撤销。

### 7.6 首次使用与空画布

- 没有数据文件时，自动建一张"我的画布"。
- 画布上没有卡片时，正中显示浅灰色提示："点左上角「+ 卡片」新建卡片，也可以把它拖到想放的位置"。有卡片后提示消失。

## 8. 卡片

### 8.1 外观

```
┌──────────────────────────────────┐
│ ●  [图标]  方案会话 · 登录改版       │
│            写 PRD、技术方案          │
└──────────────────────────────────┘
```

- 第一行：状态圆点、图标（20×20）、名称（加粗，单行，太长显示省略号）。
- 第二行：备注（灰色小字，单行，太长显示省略号）。没有备注时不显示第二行。
- 宽度随内容变化，在 180–280px 之间。鼠标停在卡片上时，显示完整的名称和备注。
- 白底、圆角、浅灰边框；选中时黑色边框；拖动时有轻微阴影。
- 状态圆点：

| 状态  | 圆点           |
| --- | ------------ |
| 未开始 | 灰色空心圆        |
| 进行中 | 粉色实心圆，带呼吸动画  |
| 已完成 | 绿色实心圆        |
| 卡住了 | 橙色实心圆        |

鼠标停在圆点上时，显示状态名。

### 8.2 新建卡片

入口：

- 单击「+ 卡片」：在当前视野中心新建。如果那个位置正好有一张卡片完全重叠，就往右下错开 24px，直到不重叠。
- 把「+ 卡片」按钮拖到画布上松手：在松手的位置新建。松手位置不在画布上（比如在左侧列表上）时，不新建。
- 右键画布空白处，选「在这里新建卡片」：在右键的位置新建。

新卡片的默认值：图标是 Claude Code，名称是"新卡片"，备注为空，状态是"未开始"。

新建后自动选中这张卡片并打开设置面板，名称输入框获得焦点，文字全选，直接打字就会替换。

没有当前画布（空状态）时，以上入口都不可用。

### 8.3 设置面板（选中一张卡片时）

从上到下：

1. 图标：图标库网格，内置 4 个在前，上传的在后；当前图标带选中框。最后一格是「上传」。点哪个图标就立即换成哪个。
2. 名称：单行输入框，必填，1–40 个字，输入时卡片实时变化。按回车或点别处时，如果去掉首尾空格后为空，恢复为这次编辑前的名称，并提示"名称不能为空"。
3. 备注：单行输入框，0–60 个字，输入时卡片实时变化。
4. 状态：四个按钮（未开始 / 进行中 / 已完成 / 卡住了），点一下立即生效。
5. 连线：列出这张卡片的所有连线，每行显示方向符号、对方卡片名、连线文字（有的话）。
   - 点某一行：选中那条连线，面板切换为连线设置。
   - 每行右侧的 ×：删除这条连线。
   - 下面的「+ 添加连线」：打开下拉框，列出当前画布上的其他卡片，可以输入名称筛选；已经连着的卡片显示"已连接"，不能选；画布上没有其他卡片时显示"没有其他卡片"。选中一张后，立即创建"本卡片 → 对方"的连线。
6. 底部按钮：「复制一张」「删除卡片」。

面板里的改动立即生效并自动保存，没有"保存""取消"按钮。

关闭面板：

- 点面板右上角的 ×，或点画布空白处：关闭面板并取消选中。
- 按 Esc：焦点在输入框里时，第一次按 Esc 先让输入框失去焦点（按"点别处"的规则保存），再按一次才关闭面板并取消选中；焦点不在输入框里时，按一次就关闭。

### 8.4 设置面板（选中多张卡片时）

- 显示"已选中 N 张卡片"。
- 状态：四个按钮，点一下把所有选中的卡片都设成这个状态（算作 1 步撤销）。
- 底部按钮：「复制一张」（每张选中的卡片各复制一张）「删除」。

### 8.5 移动

- 按住卡片拖动。多选后拖动其中任意一张，所有选中的卡片一起移动。
- 拖动时，相连的连线实时跟着变化。

### 8.6 复制一张

- 入口：右键卡片选「复制一张」，或面板里的「复制一张」按钮。
- 新卡片出现在原卡片右下方 24px 处，图标、名称、备注、状态都和原卡片一样，不复制连线。
- 复制完成后，选中新复制出来的卡片。

### 8.7 删除卡片

- 入口：选中后按 Delete 或 Backspace（焦点在输入框里时不生效，只删输入框里的文字）；右键卡片选「删除」；面板里的「删除卡片」。
- 这张卡片的所有连线一起删除。
- 不弹确认框；页面底部出现提示条"已删除 N 张卡片 [撤销]"，5 秒后消失。点「撤销」后，卡片和连线一起恢复。

### 8.8 选择

- 单击卡片：选中这一张。
- 按住 Shift 单击卡片：加选，或取消选中这一张。
- 按住 Shift 在空白处拖出一个框：框里的卡片都被选中（框选只选卡片，不选连线）。
- Cmd+A：选中当前画布上的所有卡片。
- 双击卡片：选中这张卡片，并让面板里的名称输入框获得焦点、文字全选。

## 9. 连线

### 9.1 外观

- 平滑曲线。两个端点自动落在两张卡片相互最靠近的那两条边的中点上；拖动卡片时，端点和曲线实时重新计算。
- 默认：浅灰色实线，终点有箭头；双向连线两端都有箭头。
- 相连的两张卡片中只要有一张是"进行中"：连线变成粉色虚线，沿箭头方向流动；双向连线只显示粉色虚线，不流动。
- 选中时：黑色，比平时略粗。
- 文字：显示在曲线中间，白底小字标签；没有文字时不显示标签。

### 9.2 创建连线

- 鼠标移到卡片上时，四条边的中点出现连接点。从连接点按住，拖到另一张卡片上任意位置松手，就创建一条"起点卡片 → 目标卡片"的连线，没有文字。拖动过程中，有一条虚线跟着鼠标。
- 松手位置在空白处，或在起点卡片自己身上：不创建。拖动中按 Esc：取消这次拖动。
- 两张卡片之间已经有连线时：
  - 已有 B → A，再从 A 拖到 B：改成 A ⇄ B，提示"已改为双向连线"。
  - 已有 A → B 或 A ⇄ B，再从 A 拖到 B：不变，提示"这两张卡片已经连着了"。
- 也可以用卡片设置面板里的「+ 添加连线」创建（见 8.3）。

### 9.3 设置面板（选中一条连线时）

- 选中方式：点曲线（曲线周围有较宽的可点击范围）或点文字标签。
- 面板内容：
  - 两端的卡片名称；
  - 方向：三个按钮 A → B / A ← B / A ⇄ B，点一下立即生效；
  - 文字：单行输入框，0–20 个字，输入时连线标签实时变化；
  - 「删除连线」按钮。
- 双击连线：选中连线，并让文字输入框获得焦点。
- 关闭面板的方式和卡片面板一样（见 8.3）。

### 9.4 删除连线

- 入口：选中后按 Delete 或 Backspace；右键连线选「删除」；连线面板里的「删除连线」；卡片面板连线列表里的 ×。
- 不弹确认框；提示条"已删除连线 [撤销]"，5 秒后消失。

| 画布空白处 | 在这里新建卡片、适应全部  |

- 多选状态下右键其中一张卡片：菜单项作用于所有选中的卡片（"编辑"不可用）。
- 右键没被选中的卡片：先单独选中它，再显示菜单。

### 11.3 撤销 / 重做

- 范围：当前画布里卡片和连线的操作，包括新建、删除、移动、复制、改图标 / 名称 / 备注 / 状态、连线的新建 / 删除 / 改方向 / 改文字。
- 不在范围内：画布的新建 / 重命名 / 删除、上传或删除图标、导入、视野变化（平移和缩放）、选中状态。
- 一步的大小：
  - 一次拖动（包括多选一起拖动）算 1 步；
  - 在一个输入框里连续输入，直到失去焦点，算 1 步；
  - 删除卡片连同它的连线算 1 步；
  - 多选批量改状态、批量复制、批量删除各算 1 步。
- 每张画布最多保留 100 步，超出时丢弃最早的。
- 撤销之后做了新操作，重做历史清空。
- 刷新页面后撤销历史清空；这张画布载入别处的改动后（见 12.4），撤销历史也清空，避免撤销时抹掉别处的修改。
- 撤销、重做同样会自动保存。
- 不能撤销或重做时，按钮显示为灰色，快捷键不起作用。

## 12. 保存、备份、导出导入

### 12.1 自动保存

- 每次改动后 1 秒内自动保存；连续的改动合并成一次保存。
- 视野、当前画布、小地图显示与否也会保存，下次打开时恢复。
- 右上角显示保存状态：

| 状态       | 显示                                   |
| -------- | ------------------------------------ |
| 已保存      | 灰色"已保存"                              |
| 正在保存     | 灰色"保存中…"                             |
| 连不上本地服务  | 红色"未保存：连不上本地服务，正在重试"                 |
| 写入失败     | 红色"未保存：{原因}，正在重试"（如磁盘已满、没有写入权限）       |
| 被别的标签页改过 | 红色"这张画布在别的标签页改过了" 和「重新加载」按钮           |

### 12.2 保存失败与重试

- 连不上本地服务或写入失败时：每 5 秒自动重试一次；恢复后自动保存，状态变回"已保存"。重试期间可以继续编辑卡片和连线。
- 每次保存的是整张画布的最新内容，重试多少次结果都一样，不会产生重复数据。
- 打开网页时一次载入全部画布，所以连不上服务时仍然可以切换画布，看到的是本页最后载入的内容；几张画布都有未保存改动时，各自重试。
- 有未保存改动时刷新、关闭标签页或关闭浏览器：弹出浏览器自带的离开确认（文字由浏览器决定）。
- 需要本地服务立刻处理的操作：新建 / 重命名 / 删除画布、上传 / 删除图标、导入、导出。连不上服务时这些操作不生效，提示"连不上本地服务，请重新打开会话连接后再试"。

### 12.3 启动时备份

- 每次启动本地服务时，如果数据文件能正常读取，就把数据文件连同它用到的上传图标一起备份到备份目录，文件名带时间。
- 只保留最近 10 份，更早的自动删除。
- 数据文件读不出来时不做这次备份，避免用损坏的文件挤掉好的备份。

### 12.4 多个标签页

- 切回某个标签页时：画布列表自动刷新；如果当前画布在别处改过，而这个标签页没有未保存改动，就自动载入最新内容。
- 两个标签页都在改同一张画布：标签页 A 先保存成功后，标签页 B 再保存时会被拒绝。此时：
  - B 的保存状态显示"这张画布在别的标签页改过了"和「重新加载」按钮；
  - B 的这张画布变为只读：不能拖动、不能编辑，「+ 卡片」和撤销、重做都不可用；
  - 点「重新加载」后，显示最新内容，恢复编辑；B 被拒的那次改动丢失（已知限制）；
  - B 切到其他画布不受影响，再切回来时载入最新内容。
- 画布在 A 里被删除，而 B 正在显示这张画布：B 下次保存或切回标签页时弹出"这张画布已被删除"（文案见第 15 节），点「知道了」后切换到列表里的第一张画布；没有画布了就显示空状态。

### 12.5 数据文件损坏

- 启动时数据文件读不出来：本地服务不覆盖它，把它改名保留（文件名加"-损坏-时间"），然后自动用最近一份能读的备份恢复。
- 打开网页时，顶部显示一次提示："数据文件损坏，已从 {备份时间} 的备份恢复。损坏的文件保留在 {路径}"，带「知道了」按钮。
- 没有能读的备份：从空白数据开始（自动建"我的画布"），提示："数据文件损坏，也没有可用的备份，已从空白开始。损坏的文件保留在 {路径}"。

### 12.6 导出

- 「⋯」→「导出全部数据」：浏览器下载 `会话连接-备份-YYYYMMDD-HHmm.json`，包含所有画布、卡片、连线和上传的图标。
- 有未保存改动时先保存再导出；保存不上时提示"有改动还没保存上，暂时不能导出"。

### 12.7 导入

- 「⋯」→「导入」：选择 .json 文件 → 弹出确认框（文案见第 15 节）→ 点「导入」。
- 导入的画布追加到列表末尾，名称不变（允许重名）；图标按内容去重。导入后切换到导入的第一张画布。
- 要么全部导入成功，要么什么都不导入。
- 失败提示：

| 情况                | 提示                          |
| ----------------- | --------------------------- |
| 不是本程序导出的文件，或文件损坏  | 文件格式不对，没有导入任何内容             |
| 文件来自更新版本的会话连接     | 这个文件来自更新版本的会话连接，请先升级后再导入    |
| 超过 1 GB           | 文件太大（超过 1 GB），没有导入任何内容      |
| 连不上本地服务           | 连不上本地服务，请重新打开会话连接后再试       |

- 导入过程中本地服务断开（不知道导入成没成功）：提示"连不上本地服务，导入结果待确认；重新打开会话连接后会自动核对"，不自动重新导入。服务恢复后自动核对：
  - 已经导入成功：切到导入的第一张画布，提示"导入已完成"；
  - 没有导入：提示"导入没有完成，可以重新导入"；
  - 核对时还是连不上：继续保持"待确认"。

## 13. 中断与异常

| 情况                       | 结果                                       |
| ------------------------ | ---------------------------------------- |
| 刷新、关闭标签页、地址栏跳走、关闭浏览器（都已保存） | 不拦截；再次打开时回到上次的画布和视野                      |
| 同上，但有未保存改动               | 浏览器自带的离开确认                                |
| 页面开着时退出应用（或本地服务意外退出）     | 保存状态变红并自动重试；再点应用图标启动后（端口相同）自动补存          |
| 电脑休眠后唤醒                  | 服务还在就正常；服务不在了按上一条处理                       |
| 输入框正在编辑时：切换画布、点空白处、选别的卡片 | 先按"点别处"的规则保存这次输入，再执行                      |
| 弹窗打开时：取消、Esc、点遮罩、×       | 都等于取消，什么都不改                               |
| 拖连线途中按 Esc               | 取消这次拖动，不创建连线                              |
| 拖卡片途中按 Esc               | 不起作用；松手后可以撤销                              |
| 上传图标途中关闭面板               | 上传继续；完成后只加入图标库，不改卡片                       |
| 重启后换了端口                  | 旧标签页一直连不上；用新打开的标签页（已知限制）                  |
| 磁盘满、没有写入权限               | 保存失败，状态显示原因，每 5 秒重试                        |

## 16. 性能、兼容与安全

- 系统：只支持 macOS。
- 浏览器：最新版 Chrome（验收用）、Edge、Safari。
- 性能：
  - 服务没运行时，从点击应用图标到页面显示不超过 3 秒；
  - 一张画布有 200 张卡片、300 条连线时，拖动卡片没有明显卡顿，打开这张画布 1 秒内显示完成。
- 离线：页面不请求任何外网资源（图标、字体都在本地），断网也能正常使用。
- 安全：服务只监听 127.0.0.1；上传的 SVG 以图片方式显示，里面的脚本不会执行；数据只存在本机。
- 兼容：数据文件带版本号；以后升级时自动迁移旧数据，导入旧版本导出的文件也能用。
- 对现有功能的影响：无（新项目）。

## 17. 验收标准

测试数据：200 张卡片、300 条连线的导入文件，以及"找不到 Node.js"的模拟方法，由开发方提供。

### 应用与启动

- A1 在项目目录运行 `npm run app` → 生成 `/Applications/会话连接.app`，图标是叼信的鸽子（与 `assets/app-icon/app-icon-preview.png` 一致）；拖进程序坞后显示清晰。

## 18. 状态 × 操作 交叉检查

| 页面状态                 | 可以做                          | 不能做 / 特殊处理                                                           |
| -------------------- | ---------------------------- | -------------------------------------------------------------------- |
| 没有画布（空状态）            | 新建画布、导入、导出                   | 「+ 卡片」、撤销、重做不可用                                                     |
| 空画布                  | 全部操作                         | 显示空画布提示；「适应全部」回到 100%                                                |
| 没有选中                 | 全部操作                         | Delete 无反应                                                           |
| 选中一张卡片（面板打开）         | 全部操作                         | Delete 删除这张卡片；「+ 卡片」后改为选中新卡片；切换画布后取消选中                                |
| 选中多张卡片               | 批量改状态、复制、删除、一起拖动             | 面板不显示单卡设置；右键菜单"编辑"不可用                                                |
| 选中一条连线               | 改方向、改文字、删除                   | Delete 删除这条连线                                                         |
| 输入框有焦点               | 输入                           | Delete、Backspace、Cmd+Z、Cmd+Shift+Z、Cmd+A 只作用于输入框；点别处、切换画布先保存输入；Esc 先失去焦点 |
| 弹窗打开                 | 操作弹窗                         | 画布不可操作，快捷键不作用于画布；Esc、遮罩、× 等于取消                                       |
| 拖动中（卡片或连线）           | 继续拖动                         | Cmd+Z 不起作用；拖连线时 Esc 取消；拖卡片时 Esc 不起作用                                |
| 保存失败（连不上服务或写入失败）     | 编辑卡片和连线（稍后补存）、撤销、重做、切换画布       | 新建 / 重命名 / 删除画布、上传 / 删除图标、导入、导出：提示后不生效；刷新、关闭弹离开确认                        |
| 只读（被别的标签页改过）         | 「重新加载」、切换到其他画布、新建画布、平移缩放       | 编辑、拖动、「+ 卡片」、撤销、重做、导出都不可用                                            |
