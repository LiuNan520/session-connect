# 连线活跃开关 PRD

- 版本：v3 · 2026-10-23
- 状态：已归档（2026-10-23；用户验收通过）
- 编写：Claude
- 基于：`docs/prd/会话连接-PRD.md` v8（已归档）

## 1. 背景与目标

现在的规则（会话连接 PRD 9.1，代码 `web/src/components/Board.tsx` 第 72 行）：连线两端只要有一张卡片是"进行中"，这条线就变成粉色虚线。一张卡片进行中时，它身上所有的线都会一起变，包括那些和当前工作无关的线。

例子（用户截图，2026-10-23）：「PRD二期未完成任务」进行中，它连出去的「修复本地附件上传开关」那条线也在流动，但那条线说的事情已经结束了，不应该流动。

目标：每条连线可以单独关掉"活跃"，关掉后不管两端卡片是什么状态，都显示成普通灰线。

## 2. 用语

| 词    | 含义                                                                 |
| ---- | ------------------------------------------------------------------ |
| 活跃   | 连线显示为粉色虚线（箭头也是粉色）：单向时沿箭头方向流动，双向时只是虚线不流动。                         |
| 普通灰线 | 连线显示为浅灰色实线，箭头也是浅灰色。                                               |
| 活跃设置 | 每条连线自己的一项设置，两个取值：**跟随卡片**、**不活跃**。                                 |
| 跟随卡片 | 两端卡片有一张"进行中"时活跃，否则是普通灰线，也就是现在的规则。                              |
| 不活跃  | 始终是普通灰线，不看两端卡片的状态。                                                 |

"选中"时连线是黑色、略粗，这一点不受活跃设置影响（见 4.2）。

## 3. 范围

### 本期做

1. 每条连线增加活跃设置，默认"跟随卡片"。
2. 连线设置面板增加「活跃」一项，可以切换。
3. 画布按活跃设置显示连线。
4. 活跃设置跟其他连线改动一样：自动保存、可以撤销 / 重做、导出导入时一起带上。

### 本期不做

- 第三档"总是活跃"（两端都不在进行中也流动）：用户 2026-10-23 选了只做两档。
- 在连线右键菜单、卡片面板的连线列表里切换（用户 2026-10-23 只要连线面板这一个入口）。
- 卡片面板的连线列表里标出哪条线不活跃。
- 不活跃的线换一种样子（比如灰色虚线）：用户 2026-10-23 选了和普通灰线完全一样。
- 批量设置多条连线（现在本来就不能同时选中多条连线）。

### 二期（候选，未承诺）

- 无。

### 已知限制

- 把代码退回到本功能之前的版本后：数据文件里的活跃设置会被旧版本忽略，所有连线回到"跟随卡片"的效果；旧版本再保存这张画布时，活跃设置会从数据文件里消失。原因是旧版本读取数据时只保留它认识的字段（`server/src/validation.ts` 第 73 行）。

## 4. 规则

### 4.1 显示规则

| 活跃设置 | 两端卡片的状态      | 单向连线               | 双向连线          |
| ---- | ------------ | ------------------ | ------------- |
| 跟随卡片 | 至少一张"进行中"    | 粉色虚线，沿箭头方向流动，粉色箭头 | 粉色虚线，不流动，两端粉色箭头 |
| 跟随卡片 | 都不是"进行中"     | 普通灰线               | 普通灰线          |
| 不活跃  | 任何状态         | 普通灰线               | 普通灰线          |

- 卡片状态改变、活跃设置改变、方向改变后，连线立即按上表重新显示。
- 不活跃的线和两端都不在进行中的线看起来完全一样，画布上不加任何额外标记。
- 活跃设置只影响连线的样子，不影响卡片：卡片的状态圆点、呼吸动画都照旧。

### 4.2 选中时

- 选中的连线照旧显示为黑色、略粗，箭头也是黑色，不管活跃设置是什么。
- 取消选中后按 4.1 显示。

### 4.3 新建和合并连线

| 情况                                     | 活跃设置          |
| -------------------------------------- | ------------- |
| 从连接点拖出新连线                              | 跟随卡片          |
| 卡片面板「+ 添加连线」新建                         | 跟随卡片          |
| 已有 B → A，再从 A 拖到 B，改成 A ⇄ B（会话连接 PRD 9.2） | 保留原来那条线的设置，不重置 |
| 改方向                                    | 不变            |
| 改文字                                    | 不变            |

理由：合并后还是原来那条线（同一对卡片最多一条线），只是多了一个箭头，用户之前关掉的设置不应该被悄悄打开。

### 4.4 复制、删除

- 复制卡片不复制连线（现有行为），和本功能无关。
- 删除卡片会连带删掉它的连线；撤销后连线回来，活跃设置也回到删除前的样子。删除连线后撤销同理。

## 5. 界面

### 5.1 连线设置面板

在"方向"和"文字"之间加一项：

- 标题：活跃
- 两个按钮：「跟随卡片」「不活跃」，样式和"方向"的按钮一样，当前取值显示为选中样式。
- 点一下立即生效，不用确认。点当前已经选中的那个按钮：没有变化，也不产生撤销步骤。
- 按钮旁边不加说明文字。

调整后面板从上到下：两端的卡片名称、方向、活跃、文字、「删除连线」。

### 5.2 不可用的时候

- 画布只读（被别的标签页改过，见会话连接 PRD 12.4）：两个按钮显示为灰色，点了没反应；和"方向"按钮一样。
- 其他时候都可以切换，包括两端卡片都不在进行中的时候（这时切换后画布上看不出变化，等卡片进入进行中才有区别）。

### 5.3 不变的地方

- 连线右键菜单：仍然只有"编辑""删除"。
- 卡片面板的连线列表：每行仍然只显示方向符号、对方卡片名、连线文字。
- 快捷键：不加新快捷键。
- 小地图：不显示连线，不受影响。

## 6. 撤销 / 重做

- 切换活跃设置算 1 步，归入会话连接 PRD 11.3 的撤销范围（"连线的新建 / 删除 / 改方向 / 改文字"之后加"改活跃设置"）。
- 撤销、重做后，连线样子立即变化；如果这条线正被选中，面板里的按钮也跟着变。
- 其他撤销规则（每张画布最多 100 步、刷新后清空等）不变。

## 7. 保存、多标签页、导出导入

- 保存：和改方向一样，改动后 1 秒内自动保存；保存失败、重试、离开确认的规则不变（会话连接 PRD 12.1、12.2）。服务停止期间也可以切换，恢复后补存。
- 多个标签页：和其他画布改动一样（会话连接 PRD 12.4），没有新规则。
- 导出：导出文件里每条连线带上活跃设置。
- 导入：

| 导入文件里的连线          | 结果                             |
| ----------------- | ------------------------------ |
| 带合法的活跃设置          | 照原样导入                          |
| 没有活跃设置（本功能之前导出的文件） | 按"跟随卡片"导入，正常成功                 |
| 活跃设置的值不合法         | 整个文件不导入，提示"文件格式不对，没有导入任何内容"（和方向不合法时一样） |

## 8. 历史数据与兼容

- 已有的数据文件、启动备份里的连线都没有活跃设置，一律按"跟随卡片"处理。打开后所有连线的样子和升级前完全一样，不提示、不弹窗。
- 不改数据文件的版本号；不需要迁移步骤。数据文件里什么时候写入活跃设置由技术方案定，用户看到的效果必须和上面一致。
- 代码回退到旧版本的情况见第 3 节"已知限制"。

## 9. 状态 × 操作 交叉检查

| 状态                 | 切换活跃设置                   | 其他说明                     |
| ------------------ | ------------------------ | ------------------------ |
| 选中一条连线（面板打开）       | 可以，立即生效                  | —                        |
| 没选中连线              | 没有入口                     | —                        |
| 两端都不在进行中           | 可以，画布上看不出变化              | 之后有卡片进入进行中时按新设置显示        |
| 有一端进行中             | 可以，线立即在粉色虚线和普通灰线之间切换     | —                        |
| 只读                 | 不可以，按钮灰色                 | —                        |
| 保存失败（连不上服务或写入失败）   | 可以，稍后补存                  | —                        |
| 输入框有焦点（正在改连线文字）     | 点按钮先让输入框失去焦点、保存文字，再切换    | 文字和活跃设置各算 1 步撤销          |
| 弹窗打开               | 不可以（画布和面板都被弹窗挡住）         | —                        |
| 拖动中                | 不可以（拖动时点不到面板）            | —                        |

## 10. 验收标准

准备：用隔离数据启动（`SESSION_CONNECT_HOME=<临时目录> node dist/server/index.js --mode dev`），画布上放 A、B、C 三张卡片，连线 A → B、C → A。

### 默认与兼容

- B1 导入一份本功能之前导出的文件（或用升级前的数据目录启动），其中有卡片在进行中 → 导入成功，所有连线的样子和升级前一样；选中任一连线，面板「活跃」显示"跟随卡片"。
- B2 新拖一条连线、用卡片面板「+ 添加连线」新建一条 → 两条线的面板都显示"跟随卡片"。

### 显示

- B3 把 A 设成进行中 → A → B、C → A 两条线都是流动的粉色虚线。选中 A → B，点「不活跃」，再点空白处取消选中 → A → B 变成普通灰线（线和箭头都是浅灰色），C → A 仍在流动。
- B4 接 B3，把 A 改成已完成再改回进行中；把 B 也设成进行中 → A → B 一直是普通灰线。
- B5 接 B3，把 A → B 改成 A ⇄ B → 仍是普通灰线，两端箭头都是灰色；再点「跟随卡片」→ 变成粉色虚线、不流动，两端箭头粉色。
- B6 选中一条不活跃的线 → 显示为黑色略粗；取消选中 → 回到普通灰线。
- B7 两端都不在进行中时点「不活跃」→ 画布上看不出变化；再把一端设成进行中 → 这条线仍是普通灰线。
- B8 点当前已选中的按钮 → 没有变化，撤销按钮的状态不变（之前不能撤销的仍是灰色）。

### 新建、合并、删除

- B9 C → A 设成不活跃，再从 A 的连接点拖到 C → 提示"已改为双向连线"，这条线仍是不活跃。
- B10 删除卡片 B（A → B 是不活跃的）→ 撤销 → A → B 回来，仍是不活跃；单独删除这条线再撤销，结果一样。

### 撤销 / 重做

- B11 切换一次活跃设置 → Cmd+Z 回到原来的设置（画布和面板都变）→ Cmd+Shift+Z 又回到新设置。各一步。
- B12 正在连线文字输入框里打字时点「不活跃」→ 文字先保存；按两次 Cmd+Z，第一次撤销活跃设置，第二次撤销文字。

### 保存、只读、导出导入

- B13 切换后刷新页面 → 设置保留。
- B14 停掉本地服务后切换 → 保存状态显示红色"未保存：连不上本地服务，正在重试"；重新启动服务后自动变回"已保存"，刷新后设置保留。
- B15 让画布进入只读（两个标签页先后修改同一张画布）→ 被拒的标签页里，连线面板「活跃」两个按钮是灰色，点了没反应。
- B16 有不活跃连线时导出，再导入这个文件 → 导入的画布里对应连线仍是不活跃。
- B17 手工把导出文件里某条连线的活跃设置改成不合法的值再导入 → 提示"文件格式不对，没有导入任何内容"，画布列表没有变化。

### 回归

- B18 会话连接 PRD 的连线验收 A22–A28 全部仍然通过（A27 只针对"跟随卡片"的连线）。
- B19 连线右键菜单仍是"编辑""删除"；卡片面板连线列表的样子不变。
